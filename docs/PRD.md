# PRD — EntregaRota (MVP)

## O que é
App para distribuição local: o entregador vê a **rota do dia**, faz **check-in** com geolocalização (ping no mapa) e registra **pendências**.

## Fora do MVP
- Otimização avançada de rota
- Integração com frota de terceiros

## Usuários
- Operador: monta rota do dia
- Entregador: executa e faz check-in

## Domínio
